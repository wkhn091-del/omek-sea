# עומק · ים חי (עותק)

עותק של אתר עומק עם רכיב **ים חי** (WebGL / `fx-ocean`) על הצלילה בפתיחה.

- המקור `omek-studio` **לא השתנה**.
- הקובץ `public/ocean.js` הגיע מ־«ים חי · רכיב ים לאתר.html».
- ה־Hero משתמש בתחנות צלילה עם אותו קופי של עומק (כותרת + שכבות העומק).

```bash
npm install
npm run dev
```
